# Birthday Countdown

A responsive birthday page with a live November 24 countdown, all six supplied photos, an animated calendar, a desktop cursor trail, a photo lightbox, five birthday notes, a confetti button, and a WhatsApp link with a prewritten birthday greeting. The WhatsApp link opens a draft for Shayaan; the visitor taps Send in WhatsApp.

The page is a single static HTML file with photos embedded, so it deploys without a build step.
